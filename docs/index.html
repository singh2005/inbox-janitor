Inbox Janitor

Inbox Janitor is a serverless, event-driven personal automation tool built on AWS and Google Cloud that deterministically cleans your email inbox based on user engagement telemetry.

Architecture & Operation

  • Event-Driven Ingestion: Connects to GCP Pub/Sub webhooks triggered by Gmail push notifications.
  • Deterministic Logic: Evaluates a 6-message sliding window in DynamoDB. If 6 consecutive messages from a sender remain unread, the sender's policy switches from ALLOW to DELETE.
  • Self-Healing: Automatically reverts to ALLOW if a user manually reads or restores a trashed email.

Privacy Policy

Inbox Janitor is a private, single-user open-source utility built solely for personal email organization.

  • Data Access: Uses the https://www.googleapis.com/auth/gmail.modify scope to inspect unread message metadata and move engagement-matched messages to Gmail Trash.
  • Data Storage: No email body contents, attachments, or personal messages are ever stored. Only message IDs and sender email addresses are stored in encrypted AWS DynamoDB tables.
  • Data Sharing: No data is collected, sold, transmitted, or shared with third parties.
